# 📚 Exercícios com Vetores (Arrays) em C#

Este repositório contém dois exercícios simples utilizando **arrays em C#**, focados em lógica de programação e manipulação de vetores:

1. 📝 **Cálculo de Médias de Alunos**
2. 🔍 **Busca de Nomes com Repetição (goto)**

---

## 📝 1. Cálculo de Médias de Alunos

Este programa solicita o nome e duas notas para 5 alunos. Em seguida, ele exibe as notas e a média de cada aluno.

### ✨ Funcionalidades:

- Cadastro de nome e duas notas por aluno;
- Cálculo da média individual;
- Exibição organizada dos dados.


---

## 🔍 2. Busca de Nomes (com `goto`)

Neste programa, o usuário cadastra 10 nomes e pode procurar por um nome específico. Caso o nome não seja encontrado, o programa solicita outra tentativa até que o nome seja achado.

### ✨ Funcionalidades:

- Armazena 10 nomes digitados pelo usuário;
- Permite buscar por um nome digitado;
- Usa `goto` para repetir a busca até que o nome seja encontrado.
